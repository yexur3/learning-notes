# learning-notes

A collection of small coding exercises and coursework from university and self-study. These are learning exercises, not portfolio projects — for production-quality work, see [Cipher](https://github.com/yexur3/Cipher) and my other pinned repositories.

## Structure

- **`java-projects/`** — small Java exercises (OOP practice, simple CRUD apps, simulations)
- **`web-basics/`** — early frontend/Angular exercises and coursework
- **`solidity-projects/`** — first experiments with Solidity and smart contracts
- **`c-projects/`** — small C exercises

Each subfolder is a standalone exercise, kept mostly as originally written.
